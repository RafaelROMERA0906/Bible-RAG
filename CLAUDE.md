Objectif : construire un RAG sur la Bible Louis Segond 1910, étape par étape.

## Comment m'aider

## Conventions
- Gestionnaire : uv (`uv add`, `uv run`), jamais pip directement.
- Code et commentaires en anglais, explications en français.
- Code dans `src/bible_rag/`, tests dans `tests/`, notes dans `docs/journal.md`.
